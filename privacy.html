GFIT TEST BACKUPS

Privacy policy

How the owner's data is handled.

Last updated: 2 October 2026

Who operates this tool

G-Fit Tech operates GFit TEST Backups for its owner's private test backup and recovery work. This policy covers the backup tool and this information website. Contact: gfittechnology@gmail.com.

Google data we access

After the owner gives consent, the tool accesses the Google account email address, Drive storage usage and limits, the designated folder's details and sharing permissions, and backup files and their metadata in that folder. Metadata includes file identifiers, names, creation times, sizes, backup labels and integrity checksums.

The requested Google Drive permission technically allows access to all Drive files. The tool applies its own restrictions to the designated backup folder and archives marked as belonging to this tool. It does not deliberately read unrelated documents or photos.

How the data is used

Account and folder information are used to confirm the expected owner, require private storage and check free space. Backup contents and metadata are used to upload encrypted archives, confirm a download is complete, perform recovery checks, and apply the configured retention rules.

Google data is not sold, used for advertising, or used to train general-purpose AI models. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Database contents and encryption

Archives contain test database records, schema and recovery metadata, including account identity records and password hashes where present. Backups are encrypted before being sent to Google Drive. The owner keeps a separate recovery key.

During backup and recovery tests, authorized automation temporarily handles decrypted database data. Encryption of a saved archive does not mean that its data stays encrypted while a recovery test is running.

Storage and service providers

  • Google Drive stores encrypted archives and their file metadata in the owner's private folder.
  • GitHub Actions runs the private backup and recovery jobs. Protected credentials and the recovery key are stored in GitHub Actions secrets. Jobs use temporary working files; the workflow does not upload database dumps as GitHub artifacts.
  • The owner's computer may hold protected credentials, the recovery key, encrypted backup copies and temporary files used for local recovery checks.
  • Healthchecks.io receives job status signals to send monitoring emails. The integration does not send database records or backup contents.

These services process the information needed to provide their functions under their own policies. The tool's operators access data only for authorized backup, recovery, maintenance or support work.

Retention and deletion

Automatic retention keeps at least the newest 30 matching archives. An older archive becomes eligible for Trash only when it is also over 30 days old and a new backup has been uploaded and verified. The tool does not remove unrelated Drive files. Files in Trash remain subject to Google's deletion rules and count toward storage while retained there.

The owner can change retention, delete stored archives, remove local copies and revoke stored credentials. Historical backups can contain records removed from the current database until those backups are deleted. Recovery keys are kept separately for as long as the corresponding archives are needed.

Choice and revocation

The owner can revoke this tool's access from Google Account connections. Revocation stops future Google access once the revocation takes effect; it does not delete existing archives, local copies or credentials held by other services. The owner should remove those separately when ending use.

For access, correction or deletion questions, contact gfittechnology@gmail.com.

This information website

These pages have no sign-in form, advertising, analytics code or tracking scripts. The hosting provider, GitHub Pages, logs visitor IP addresses for security purposes as described in the GitHub Privacy Statement. Emailing us shares the information you choose to send with G-Fit Tech and the email providers involved.

Policy changes

We will update this page when the tool's data practices change and show the new date above. Material changes requiring new Google permissions will require the owner's consent.
